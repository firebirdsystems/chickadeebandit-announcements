# Announcements

A [Chickadee Bandit](https://chickadeebandit.com/app-library/announcements) app.

Post household announcements with admin approval, expiration, and notification support — including optional email to every member.

## Features

- Admin approval before an announcement is published.
- Expiration dates.
- Notifications to the audience you choose.
- Group targeting.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-announcements/releases/latest/download/bundle.json
```
